# Datos

Esta carpeta contiene los datos utilizados en el desarrollo del Trabajo Fin de Grado.

## Logs de batallas

Los registros originales de las batallas descargadas desde Pokémon Showdown se encuentran organizados en las carpetas:

* `batallas_ou_logs1410`
* `batallas_ou_logs1520`
* `batallas_ou_logs1630`
* `batallas_ou_logs1740`
* `batallas_ou_logs1850`
* `batallas_ou_logs1960`
* `batallas_ou_logs2070`
* `batallas_ou_logs2180`
* `batallas_ou_logs2290`

Cada una de estas carpetas contiene los archivos `.log` correspondientes a los combates descargados para los distintos rangos de Elo considerados durante la recopilación de datos.

## Bases de datos procesadas

Las bases de datos generadas durante las fases de preprocesamiento y análisis se encuentran en el archivo comprimido `csvs.zip`.

Este archivo contiene los distintos ficheros CSV utilizados a lo largo del proyecto. Debido al tamaño de algunos de estos archivos, se ha optado por distribuirlos en formato comprimido para facilitar su almacenamiento y descarga desde GitHub.
