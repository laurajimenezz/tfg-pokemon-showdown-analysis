# Exploración de Patrones y Predicción de Resultados en Batallas Pokémon

Repositorio correspondiente al Trabajo Fin de Grado del Grado en Estadística.

## Descripción

Este proyecto tiene como objetivo analizar información procedente de combates competitivos de Pokémon Showdown y desarrollar modelos de aprendizaje automático capaces de predecir el ganador de una batalla a partir de la información disponible durante su desarrollo.

Para ello, se llevó a cabo un proceso completo que incluyó:

* Obtención automática de datos mediante técnicas de web scraping.
* Procesamiento y transformación de logs de combate.
* Construcción de bases de datos de Pokémon y batallas.
* Análisis estadístico descriptivo y exploratorio.
* Desarrollo y evaluación de modelos de clasificación basados en aprendizaje automático.

## Estructura del repositorio

### data/

Contiene los datos utilizados en el proyecto:

* Carpetas `batallas_ou_logs*` con los logs originales descargados desde Pokémon Showdown.
* Archivo `csvs.zip`, que contiene las bases de datos procesadas utilizadas durante las distintas fases del análisis.

### code/

El repositorio incluye los scripts desarrollados para:

* Obtención de datos.
* Procesamiento de logs.
* Limpieza y preprocesamiento.
* Análisis estadístico.
* Entrenamiento y evaluación de modelos predictivos.
